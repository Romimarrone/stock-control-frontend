# StockControl - Frontend

Interfaz web para la gestión de inventario, catálogo de productos y control de existencias en tiempo real. Desarrollada con **React**, **Vite** y **Tailwind CSS**.

---

## 🚀 Tecnologías Utilizadas

* **React** (Vite)
* **React Router DOM** (Enrutamiento SPA)
* **Tailwind CSS** (Estilos UI)
* **Lucide React** (Iconografía)
* **Axios** (Cliente HTTP)
* **SweetAlert2** (Notificaciones e interacciones)
